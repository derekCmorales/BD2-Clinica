# Casos de uso

Compartidos por las cuatro instituciones. El motor lo elige `EnrutadorDeMotor` con el `institucionId` del JWT.

- `crear-paciente-nuevo.ts`
- `registrar-consulta.ts`
- `agregar-diagnostico.ts`
- `recetar-medicamento.ts`
- `archivar-expediente.ts`
- `casos-extension.ts` — cita, examen, medición, vacuna, pieza
- `consultas-expediente.ts` — lectura y búsqueda
